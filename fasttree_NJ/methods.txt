Multiple sequence alignments were generated from Foldseek databases containing amino acid and 3Di sequences using FoldMason (release 4-dd3c235). FoldMason was run with structuremsa --fast 1 --refine-iters 0, disabling residue neighborhood scoring and additional alignment refinement. The resulting amino acid alignment was used to infer an unrooted phylogenetic tree with FastTreeMP v2.2.0 using -fastest -noml -spr 0 -nosupport. This configuration performs accelerated heuristic neighbor joining followed by minimum-evolution nearest-neighbor interchange (NNI) refinement, without subtree-prune-regraft moves, maximum-likelihood optimization, or local support estimation.
